# 작업 기록

기준일: 2026-10-14 (한국 시간)

## 보관한 내용

- 사용자 제공 ZIP의 원본 201·202·203 분류 코드와 키워드·플랫폼 사전.
- 기존 클라우드에서 사용한 Python 환경 설정, 설치 스크립트와 패키지 고정 목록.
- 원본 202 분류 함수를 호출하는 전체 행 실행기. 행별 시간 제한, SQLite 체크포인트, CSV·Excel 출력 및 재개 기능을 포함합니다.
- 기능·모델 검증 도구와 원본 CLI의 로컬 사이트 검증 도구.

모델 체크포인트, ZIP, 가상환경, 캐시, 업체 원본 데이터와 행별 결과는 Git에 포함하지 않았습니다. `cloud/`와 `scripts/`는 기존 클라우드 경로를 사용하는 작업 도구의 스냅샷입니다.

## 이번 대화에서 직접 확인한 사항

- 클라우드 작업공간에 연결해 기존 파일에 접근했습니다.
- 저장소에는 README만 있어 원본 ZIP에서 코드·모델·사전·예전 CSV 등 20개 파일을 복원했습니다. 복원 파일은 저장된 원본 SHA-256과 모두 일치했습니다.
- Python 3.8.20, CPU PyTorch 2.4.0+cpu 환경에서 캐시된 기본 모델과 제공된 202 체크포인트를 불러왔습니다.
- 동일한 검증 문장에 대해 평가 모드의 202 BERT 예측을 두 번 실행해 두 결과가 1로 일치함을 확인했습니다. 이는 실행 확인이며 예측 정확도 검증은 아닙니다.
- 기존 ZIP의 CSV에는 `사업체명`, `홈페이지1` 두 열과 4,670행이 있습니다.

## 이전 대화에서 보고된 작업

아래는 제공된 이전 대화와 보존된 작업 기록의 내용이며, 이번 저장소 업로드 과정에서 전체를 다시 실행한 결과는 아닙니다.

- 201·202·203 BERT 예측, 브라우저 기반 키워드 분류, 앱 링크 탐지, 한국어 OCR 및 Excel 입출력 검증.
- 로컬 검증 사이트를 사용한 원본 CLI의 CSV → 분류 → Excel 출력 확인.
- 전체 행 실행기의 실제 분류, URL 오류 분리, 저장·재개 확인.
- 예전 CSV 4,670행의 처리 시도: 분류 성공 8행, URL 오류 70행, 접속·수집 실패 4,592행. 다수의 HTTP 503이 발생했으므로 전체 예측 성공으로 볼 수 없습니다.
- 일부 실패 사이트의 후속 재확인에서 정상 페이지가 관측돼, 접속 실패를 사이트 폐쇄로 판단할 수 없음을 확인했습니다.

## 미완료 사항

최신 파일 `통신판매사업자_ALL_서울특별시 전체.csv`는 채팅에 첨부됐으나 실행 도구의 파일 전송 한도인 32MiB를 초과했습니다. 최신 CSV의 열·행 수 확인, 전처리, 모델 분류 및 검토 라벨링은 아직 시작하지 못했습니다.

다음 단계는 전송 가능한 압축본 또는 분할 파일을 받아 원본을 보존하며 필요한 열과 홈페이지가 있는 행을 스트리밍으로 추리는 것입니다. 이후 100~200건 표본에서 다음을 작성할 예정입니다.

- 모델 예측과 별도의 검토 라벨: `202`, `Not-202`, `판단 불가`.
- 판단 이유, 근거 URL 및 접속 상태.
- 판단 가능한 표본의 정확도·정밀도·재현율.

웹 근거에 따른 검토 라벨은 참고 정답이며, 근거가 부족한 행은 판단 불가로 남깁니다. 업체별 라벨 결과나 정확도 수치는 아직 생성하지 않았습니다.
